# 저장소 설치 — 구글 시트 + Apps Script (무료 · 카드 등록 없음 · 약 5분)

참석 여부는 **시트 「참석」**, 방명록은 **시트 「방명록」**, 하객 사진은 **드라이브 폴더 「청첩장 하객 사진」**에 쌓입니다. 두 분 구글 계정 안에만 저장되고, 방명록 비밀번호는 해시로만 남습니다.

1. drive.google.com → 새로 만들기 → **Google 스프레드시트** (이름 예: `청첩장 응답`)
2. 시트 메뉴 **확장 프로그램 → Apps Script**
3. 편집기의 `Code.gs` 내용을 지우고 이 폴더의 `Code.gs` 를 통째로 붙여 넣기 → 저장
4. 위쪽 함수 선택에서 **`setup`** 고르고 **실행** → 권한 검토 → 본인 계정 → 「고급 → 안전하지 않은 페이지로 이동」 → 허용
   (탭 3개와 드라이브 폴더가 생깁니다)
5. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**
   - 설명: 청첩장 · **다음 사용자 인증 정보로 실행: 나** · **액세스 권한: 모든 사용자**
6. **배포** → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 알려 주세요.
   → `src/invitation.html` 의 `window.WEDDING_API = '';` 에 넣고 다시 빌드합니다.

## 바꿀 수 있는 값 (`Code.gs` 맨 위 `CFG`)
| 이름 | 기본 | 뜻 |
|---|---|---|
| `PHOTO_OPEN_AT` | 2027-05-29 13:30 | 하객 사진 올리기 시작(예식 1시간 전) |
| `PHOTO_CLOSE_AT` | 2027-06-30 | 사진 올리기 마감 |
| `MAX_PHOTO_BYTES` | 4 MB | 장당 한도(화면에서 1600px 로 줄여 보내서 보통 0.3~0.6 MB) |
| `WRITES_PER_MIN` | 60 | 전체 쓰기 상한(장난 막기) |

`Code.gs` 를 고친 뒤에는 **배포 → 배포 관리 → 수정 → 버전: 새 버전 → 배포** 를 해야 반영됩니다(URL 은 그대로).

## 확인
- 방명록 지우기 = 시트에서 줄을 지우지 않고 「지움」 칸에 시각만 적습니다(되살리려면 그 칸을 비우면 됩니다).
- 참석 여부는 같은 휴대폰에서 다시 보내면 그 줄이 고쳐집니다.
